# Contributing

This is a personal portfolio, but precise bug reports and accessibility
improvements are welcome.

## Before opening a pull request

1. Create an issue that explains the user-visible problem.
2. Keep the change focused and avoid adding private or personal data.
3. Install dependencies with `npm ci`.
4. Run `npm run check`.
5. Describe the impact and verification performed in the pull request.

Do not include generated build output, environment files, credentials, customer
information or internal planning documents.
